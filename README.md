🧵 String Questions Practice

This repository contains a collection of **Python string-based practice questions** that help strengthen core programming logic and text manipulation skills.  
It’s designed for students and beginners who want to master **string operations, logic building, and interview-level coding questions**.

---

## 📚 Topics Covered

These problems cover a wide range of string concepts:

- 🔁 Reversing a string (using loops & slicing)
- 🔡 Checking for palindrome strings
- 🧮 Counting vowels, consonants, digits & spaces
- 🪶 Changing case (upper, lower, title)
- 🔍 Finding frequency of each character
- ✂️ Removing or replacing characters
- 🪄 Checking for anagrams
- 📊 Counting words in a sentence
- 🎯 Finding the longest and shortest word
- 🧩 String concatenation & substring operations
